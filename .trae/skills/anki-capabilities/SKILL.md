# Anki 能力对比（官方 vs 本项目）

本技能对照 [Anki 官方](https://apps.ankiweb.net/) 的核心能力与本项目当前实现，帮助规划功能取舍。本项目定位是**轻量、本地、无后端**的微信多端小程序，并非完整复刻 Anki。

## Anki 简介

Anki 是开源的间隔重复记忆软件：用「笔记（Note）+ 笔记类型（Note Type）+ 卡片模板」生成卡片，用间隔重复调度算法安排复习，支持多端同步、富媒体、插件生态与丰富的导入导出。

## 能力对比表

| 能力 | Anki 官方 | 本项目 | 说明 |
| --- | --- | --- | --- |
| 间隔重复调度 | ✅ 现代 FSRS + 传统 SM-2 | ⚠️ 仅简化 SM-2 | 本项目 `utils/srs.js` 为简化 SM-2，四档评分（忘记/困难/良好/简单） |
| 牌组管理 | ✅ 多级子牌组、牌组选项 | ⚠️ 单层牌组，增删/统计 | 无子牌组、无每牌组学习上限等选项 |
| 卡片增删改 | ✅ | ✅ | 正反面卡片增删 |
| 笔记类型/模板 | ✅ 多字段、多卡片模板、正反双向 | ⚠️ 单模板单向、纯文本字段 | 用 `{{字段}}` 替换正反面 |
| 模板渲染 | ✅ HTML/CSS/JS、条件字段 `{{#field}}` | ❌ 仅纯文本替换 | 微信 WXML 不执行内嵌 HTML/JS/CSS，故用纯文本 |
| 富媒体（图片/音频/TTS） | ✅ | ❌ | 暂不支持媒体字段 |
| 导入 | ✅ CSV/`.apkg`/`.colpkg` 等 | ⚠️ 仅 Anki 风格 CSV | `utils/csv.js`，支持 `#separator/#columns/#deck` 等配置项 |
| 导出 | ✅ 多格式 | ❌ | 暂无导出 |
| 数据存储/同步 | ✅ 本地 SQLite + AnkiWeb 云同步 | ⚠️ 本地 `wx.storage`，无同步 | 数据仅在本机 |
| 统计 | ✅ 复习热图、留存率等详尽报表 | ⚠️ 概览统计 | 牌组数/卡片总数/待复习/已掌握 |

| 插件/扩展生态 | ✅ | ❌ | 无 |
| 标签/搜索/筛选 | ✅ 强大搜索语法 | ❌ | CSV 的 tags 列当作普通字段处理 |

## 本项目能力要点（现状）

- **牌组**：新建/删除、指定模板、卡片数与待复习统计、从微信会话选 CSV 导入。
- **卡片**：正反面增删；按模板字段填写并自动渲染。
- **模板**：字段管理 + `{{字段}}` 正反面模板 + 实时预览 + 内容放大倍数；更新模板可重渲染受影响卡片（`store.refreshCardsByTemplate`）。
- **复习**：翻卡 + 四档评分，SM-2 安排下次复习（`utils/srs.js`）。
- **导入**：Anki 风格 CSV，模板字段须与 `#columns` 严格匹配。

## 规划新功能时的参考

- 与 Anki 对齐但可行的方向：导出 CSV、子牌组、标签筛选、更贴近 FSRS 的调度、简单统计增强。
- 受微信平台限制、代价高的方向：HTML/JS 模板、富媒体、云同步、`.apkg` 导入、插件生态。
- 任何涉及数据结构变更，需兼容存量本地数据（见 `AGENTS.md`）。
